# SlideRule MCP Workflows

There are two primary ways to use SlideRule.

## Workflow 1: Interactive Data Processing

Use MCP tools.

Examples:

- icesat2/atl03/subset
- icesat2/atl06/subset
- gedi/l2a/subset
- data/query

These tools execute computations on SlideRule servers and return datasets.

---

## Workflow 2: Python Code Generation

Use MCP resources.

Examples:

- docs/python/getting-started
- docs/python/choosing_a_dataset
- examples/python/atl09_atmo_sampler
- openapi/sliderule.json

These resources teach the Python client APIs and provide example code.

---

Choose Workflow 1 when the user wants data.

Choose Workflow 2 when the user wants Python code.
