# sliderule-atl24

ICESat-2 Near-Shore Bathymetry Standard Data Product

## Prerequisites

* The ATL24 algorithms are developed and maintained at https://gitlab.com/3dgl/atl24_v2_algorithms and must be checked out at the same directory level as the `sliderule` repository.

## Build Dependencies

* cmake >= 3.13.0
* C++23
* XGBoost
* LibArchive
* UUID Library (libuuid)
* Readline
* Lua >= 5.3
* OpenSSL
* LibTIFF
* zlib
* Zstandard (zstd)
* cURL
