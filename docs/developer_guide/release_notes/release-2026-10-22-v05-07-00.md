# Release v5.7.x

2026-10-22

Version description of the v5.7.0 release of SlideRule Earth.

## Significant Changes

* **v5.7.0** - [d890884](https://github.com/SlideRuleEarth/sliderule/commit/d890884653653f1cae504cfd7a3084e87b737ffe) - Security hardening of the job runner: user supplied code now runs with significantly reduced permissions, the SlideRule image is protected in the runner [be1b7a3](https://github.com/SlideRuleEarth/sliderule/commit/be1b7a3d67af42c48082d0b4682916e5be08658e), and runner commands support read-only and network attributes [b11a874](https://github.com/SlideRuleEarth/sliderule/commit/b11a874313c975586cd29e05c467b533bf1ed672).  The "owner" role has been renamed to "developer" since it is no longer tied to GitHub [d2d4ce4](https://github.com/SlideRuleEarth/sliderule/commit/d2d4ce46985f9fc233782e2282459c6d2a1e5903).

## New Functionality

* **v5.7.0** - [9ed13fd](https://github.com/SlideRuleEarth/sliderule/commit/9ed13fd1527cc9562609ea24b95c4c55de49a48a) - ATL03 geolocation corrections via the new `geoloc_corr` request parameter.  The `correction` field selects the source of the correction: _"none"_ (default), _"manual"_ (user supplied local `N`, `E`, and `U` corrections in meters), or _"conus"_ (per-beam corrections retrieved from the new AMS `/ams/ATL03/geoloc_corr/{granule}` API) [013de8a](https://github.com/SlideRuleEarth/sliderule/commit/013de8a7d9504746219f023c2769855cf686dcc9).  An alert is generated the first time a correction is not available for a beam [1506b8e](https://github.com/SlideRuleEarth/sliderule/commit/1506b8ee110e3615de8e05e238bcd6a0c4922927).

* **v5.7.0** - [d5f64f6](https://github.com/SlideRuleEarth/sliderule/commit/d5f64f6476c1e42ecece1417dfc9754341b1980c) - S2 tile support in the Python client (`sliderule.s2tile`), with optimized tile reading [48a6cb4](https://github.com/SlideRuleEarth/sliderule/commit/48a6cb4eb5c2c3d55a15241bab7687ccfcdb2427).

* **v5.7.0** - [9f1a529](https://github.com/SlideRuleEarth/sliderule/commit/9f1a52921741da01a58a2757a500f2147e37becc) - Script and job runner targets for building a tiled ATL06 product (`atl06t`) [d029c16](https://github.com/SlideRuleEarth/sliderule/commit/d029c162655632041c953bcee25c40b408d4a7ed), [78fcc45](https://github.com/SlideRuleEarth/sliderule/commit/78fcc45a4f576d971e0e6ae207f04a74e9c3d0b3).

* **v5.7.0** - [7c62615](https://github.com/SlideRuleEarth/sliderule/commit/7c6261515df3a61f6645c139b520d252086c96af) - Secret management in the `pysr` runner; DuckDB added to the `pysr` environment [918145f](https://github.com/SlideRuleEarth/sliderule/commit/918145f23e0066761dfeaf9ca4210033b884f1ac).

* **v5.7.0** - [b1a168f](https://github.com/SlideRuleEarth/sliderule/commit/b1a168f9e1e203db59a7e730725eda687940ad84) - `sliderule-runner` handles duplicate submissions and has a new pruning command; statusing is faster [777743f](https://github.com/SlideRuleEarth/sliderule/commit/777743f923cf429dd5e1ead9e3d2c42c8c2c6717); the runner vCPU limit was increased [ea856ee](https://github.com/SlideRuleEarth/sliderule/commit/ea856eedb5ef48c80da4e70a0e0ffc145bab6da0).

* **v5.7.0** - [78709fb](https://github.com/SlideRuleEarth/sliderule/commit/78709fbd45b670d03dc34a6f999373d19717bcd6) - Support for the `s3access` command on Windows machines.

* **v5.7.0** - [1168359](https://github.com/SlideRuleEarth/sliderule/commit/11683596de9abbef491d360fc7e46dc7d2ec27fd) - The `cryptography` package is now optional in the Python client.
