# Release v5.9.x

2026-11-25

Version description of the v5.9.0 release of SlideRule Earth.

## Significant Changes

* **v5.9.0** - [faf256f](https://github.com/SlideRuleEarth/sliderule/commit/faf256f6087715fff2de75492953eedbf4609dd1) - Clusters migrated to m9g instances for increased public cluster capacity, and cluster nodes are now provisioned using EC2 Fleet [ada1e0b](https://github.com/SlideRuleEarth/sliderule/commit/ada1e0bbdb4185ffb173e42f667721a3c41877bb).

* **v5.9.0** - [e127f6e](https://github.com/SlideRuleEarth/sliderule/commit/e127f6e2fe1b155c5023994da920010ff1370a94) - Security hardening of the ILB: JWT validation is now applied to the `/discovery/` endpoints, audience checks are exact matches, unknown discovery paths return 404, and rate limiting is applied per user on all clusters.

## New Functionality

* **v5.9.0** - [5008f00](https://github.com/SlideRuleEarth/sliderule/commit/5008f0057ee10af80c8fa1047a24a2c99c220635) - Clusters support best-effort spot capacity in addition to on-demand nodes.  Use `--spot_capacity` in `sliderule-provisioner deploy`, or `spot_nodes` in the Python client `sliderule.scaleout`; the cluster report includes the requested `spot_capacity`.  The set of spot instance types has been limited [c026ecc](https://github.com/SlideRuleEarth/sliderule/commit/c026ecc7f7bdd93f1a6593860a33c91b4f4e4e00).

* **v5.9.0** - [e127f6e](https://github.com/SlideRuleEarth/sliderule/commit/e127f6e2fe1b155c5023994da920010ff1370a94) - New ILB usage API (`/discovery/usage`).

## Issues Resolved
