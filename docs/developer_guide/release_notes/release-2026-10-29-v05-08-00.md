# Release v5.8.x

2026-10-29

Version description of the v5.8.0 release of SlideRule Earth.

## Significant Changes

* **v5.8.0** - [67961ab](https://github.com/SlideRuleEarth/sliderule/commit/67961abfc895637b62f02010a9deaddbcabe6694) - ATL24 Release 3 is now locally hosted and served by SlideRule; the AMS has been updated to support ATL24 Release 3 [2f1266f](https://github.com/SlideRuleEarth/sliderule/commit/2f1266f7e18d95ca31c83ce51f966ea9e3c63981), along with fixes to the ATL24 dataframe [ea713d7](https://github.com/SlideRuleEarth/sliderule/commit/ea713d7600787a02f1ed6b4477146188a095c6a2), [49752cd](https://github.com/SlideRuleEarth/sliderule/commit/49752cd9f667b9b69580dc9cea58055953b84f8a).

* **v5.8.0** - [4bbfbb2](https://github.com/SlideRuleEarth/sliderule/commit/4bbfbb2a514824b99006db2b44f477a9c90a9407) - ATL24 product generation migrated into the repository as the `atl24` target, consistent with the `atl06t` target.

* **v5.8.2** - [71ff64b](https://github.com/SlideRuleEarth/sliderule/commit/71ff64bb2e55ac821bd3dc85101eae824384169f) - The `node` application has been renamed to `sliderule` (`apps/node` is now `apps/sliderule`).

## New Functionality

* **v5.8.0** - [c3ed938](https://github.com/SlideRuleEarth/sliderule/commit/c3ed9389bdf459c49ac0a637225a6f77af4964d7) - The `sliderule-runner status` command has been renamed to `fetch`.

* **v5.8.1** - [d0e52b2](https://github.com/SlideRuleEarth/sliderule/commit/d0e52b2e48bee84311203e380e8fe34679aeeace) - Support for the low latency ATL03 product (`icesat2-atl03ll`), including granule name parsing for extended product names [0d68908](https://github.com/SlideRuleEarth/sliderule/commit/0d68908a684db7cf460a89eb4ec90acca5bce174).  The Python client `sliderule.init` has a new `is_public` option to treat a private cluster as public (i.e. do not attempt to authenticate).

* **v5.8.1** - [e3186ca](https://github.com/SlideRuleEarth/sliderule/commit/e3186cac359609d61dea87bce12439f9b3803f14) - Version 3 updates to the `atl06t` product [e2296d3](https://github.com/SlideRuleEarth/sliderule/commit/e2296d3e216e557464e7d510c11a37451d2a1e30), with a low memory tile runner [d0e52b2](https://github.com/SlideRuleEarth/sliderule/commit/d0e52b2e48bee84311203e380e8fe34679aeeace) and updated benchmarks [18a5d6d](https://github.com/SlideRuleEarth/sliderule/commit/18a5d6d914ff033dadd0804d5dff1a8eb76b41f3).

* **v5.8.2** - [82e806d](https://github.com/SlideRuleEarth/sliderule/commit/82e806d617acc5f6746fd55f51a1ce1c14b0d018) - Version 4 updates to the `atl06t` product: ancillary columns added to the dataframe [2b7c6f1](https://github.com/SlideRuleEarth/sliderule/commit/2b7c6f16270f3b0a0d1486e9ab321b6db9eb6a63), new stat runner [63601f2](https://github.com/SlideRuleEarth/sliderule/commit/63601f232f566f20e4432cb178273e6d7d40242c) (fill values treated as missing [1748be9](https://github.com/SlideRuleEarth/sliderule/commit/1748be9fdd53b88d5c2943036cfb56eb5ca9fa85)), new optimized stack runner [e8174dd](https://github.com/SlideRuleEarth/sliderule/commit/e8174dd8715a910d4fdc66625077cae6a8cae5dc), [a7332e4](https://github.com/SlideRuleEarth/sliderule/commit/a7332e4230c7d60ace5d183233e536b2c05e9e04), a product manifest file [b0c3439](https://github.com/SlideRuleEarth/sliderule/commit/b0c34398014373ec5fd8d6cd7b56f0127dc0ba04), and a README [c3b6a84](https://github.com/SlideRuleEarth/sliderule/commit/c3b6a843a6a8e42607e37cdc18c0f79eed9d52a6).

* **v5.8.2** - [b7cc046](https://github.com/SlideRuleEarth/sliderule/commit/b7cc046906c2d189df17928e0fad2130ac8294df) - BlueTopo analysis and sampling scripts for ATL24, including vertical datum correction [8d4ce75](https://github.com/SlideRuleEarth/sliderule/commit/8d4ce75d4c76d5624c257c1387a91dda44d050a7), residuals [a937b22](https://github.com/SlideRuleEarth/sliderule/commit/a937b22083d3127afd58ce94f8fcfeedc9ccd1d2), and a sampling script [1494c16](https://github.com/SlideRuleEarth/sliderule/commit/1494c167eab859f6577c60829dda8bcdf05889b3).

* **v5.8.2** - [3a537ae](https://github.com/SlideRuleEarth/sliderule/commit/3a537ae90f28a0e8fd66f945084d586c151aa6dd) - `pysr` related Python code moved into the `sliderule.pysr` client module; `pysr` moved into its own app (`apps/pysr`) [ea178ec](https://github.com/SlideRuleEarth/sliderule/commit/ea178ec6aad8c8e24e231fcb2e8df1b127925b4d); `rasterio` added to the `pysr` environment [e821cda](https://github.com/SlideRuleEarth/sliderule/commit/e821cdad9f83d9600ff01c985cfc3710abab933a).

* **v5.8.2** - [d5eb7e0](https://github.com/SlideRuleEarth/sliderule/commit/d5eb7e08533ac046d3094c9c3b3d9da908ebf275) - IP tracking removed from rate limiting in the ILB.
