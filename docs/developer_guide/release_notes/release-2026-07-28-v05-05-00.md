# Release v5.5.x

2026-07-28

Version description of the v5.5.0 release of SlideRule Earth.

## Significant Changes

* **v5.4.5** - [e911e3f](https://github.com/SlideRuleEarth/sliderule/commit/e911e3f4c883b66f345a6194ac684e8cb55065e8), [5dad03c](https://github.com/SlideRuleEarth/sliderule/commit/5dad03c2526a91536a8478007f79cceb2943b1de) - The repository has been restructured so that the SlideRule node code and all supporting services now live under the top level `apps/` directory (e.g. `apps/node`, `apps/ams`, `apps/authenticator`, `apps/ilb`).

* **v5.5.1** - [#651](https://github.com/SlideRuleEarth/sliderule/pull/651) - The `yapc` score photon selection threshold was previously inert (any non-zero score behaved as a threshold of 1); it now filters as documented.  In addition, unsupported `yapc` configurations now fail loudly: versions outside 0-3 are rejected when the parameters are parsed, and versions 1-3 requested on `atl03x` raise an alert instead of silently returning all-zero scores.

## New Functionality

* **v5.4.5** - [70a3356](https://github.com/SlideRuleEarth/sliderule/commit/70a3356e8363ac221a679d3e83bd984d32deb6e2) - Continued rework of the SlideRule MCP server, including an `oauth-protected-resource` path, a ping handler, and better handling of the protocol version during initialization.

* **v5.4.5** - [f25508f](https://github.com/SlideRuleEarth/sliderule/commit/f25508f14465dee6aa4fa0519b8fce006a1446ed) - Tiered access in the GitHub authentication module.

* **v5.5.0** - [#644](https://github.com/SlideRuleEarth/sliderule/pull/644) - Asset Metadata Service (AMS) API for ICESat-2 ground tracks (`is2gt`), including support for the legacy ground track API.

* **v5.5.1** - [#651](https://github.com/SlideRuleEarth/sliderule/pull/651) - Added the `atl03_signal_class` photon selection parameter to `atl03x`, which uses the experimental per-photon signal classification (`signal_class_ph`) provided in Release 007 of ATL03.  The parameter mirrors `atl08_class` and defaults to all classifications; `signal_class_ph` is only read (and the `atl03_signal_class` column only added) when a subset of classifications is selected.

* **v5.5.1** - [6f1ed92](https://github.com/SlideRuleEarth/sliderule/commit/6f1ed9280b547f15df2c63f81e9d946a4a33b7a5) - Added bounding polygon to the ATL03 granule module.

* **v5.5.1** - [7dab15f](https://github.com/SlideRuleEarth/sliderule/commit/7dab15f8378d0bb1c78496e86aa84b10f35f2096) - Automatic certificate refresh in the intelligent load balancer.

* **v5.5.1** - [8c64281](https://github.com/SlideRuleEarth/sliderule/commit/8c642817fb799e03fdc41a33a01a18b1686294ac) - New `email` application for sending notifications to SlideRule users, including contact list management and the ability for users to unsubscribe [eb431ab](https://github.com/SlideRuleEarth/sliderule/commit/eb431abdc0009be78d8a5a0366cbcb350c0d197f).

* **v5.5.1** - [f504b48](https://github.com/SlideRuleEarth/sliderule/commit/f504b486b324f431a95c252bf53db205868b2043) - Updates for ATL24 Release 3, including updated refraction correction and uncertainty calculations, and additional columns in the bathy dataframe [d00376e](https://github.com/SlideRuleEarth/sliderule/commit/d00376ecdc2a491498d3e05074cd8d86ff155149).
